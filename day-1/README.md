 # Day 1 – Node.js Basics

## What I Learned

Today I started learning **Node.js** and the **Node ecosystem**.

### Topics Covered

* What Node.js is
* How Node.js runs JavaScript outside the browser
* What **npm (Node Package Manager)** is
* How to install and use npm packages
* What packages and dependencies are

### npm Basics

I learned how npm helps developers install and manage external libraries.

Basic commands I practiced:

npm init
npm install

### Practice

I installed and used the **cat-me** package to print a random cat in the terminal.

Command used:

npm install cat-me

Example usage in JavaScript:

const catMe = require("cat-me");
console.log(catMe());

### What I Understood

* Node.js allows JavaScript to run on the server.
* npm provides thousands of reusable packages.
* Packages help developers avoid writing everything from scratch.
